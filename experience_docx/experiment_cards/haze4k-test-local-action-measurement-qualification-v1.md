## Scientific rationale

The frozen Haze4K development oracle established large GT-privileged spatial headroom, while the closed proxy family failed to realize it out of scene. This orthogonal supplement does not change the model, action set, representation, classifier, or protected-data policy. It measures whether continuous local-action utility learned from three nested haze variants transfers to the held-out fourth variant across four fixed grid origins, while preserving location specificity, non-clipping direction, SSIM, and color safety. The target regret scene variance is unavailable before this run, so pre-run precision is recorded honestly as descriptive capacity; every terminal returns to stage 1 and never directly authorizes stage 2.
