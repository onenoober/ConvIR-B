## Scientific rationale

The archived continuous-utility precision pilot validly blocked its worst-phase scene-mean estimand because 100 independent scenes could not resolve the frozen 0.025 dB distance. It did not determine whether the excessive dispersion came from genuine scene heterogeneity or the maximum over four arbitrary grid origins. This orthogonal Stage-1 route changes only the scientific aggregation: for a predeclared uniform-random choice among the same four origins, it integrates held-out phase errors equally while retaining the two-action L-infinity contrast error, area and haze-variant weighting, 0.05 dB margin, scene grouping, official checkpoint, and protected-data prohibitions. A fixed 32-scene variance-only pilot uses the exact parent selection, withholds all primary means, and must reproduce the parent worst-phase SD before its new precision result is valid.
