## Hypothesis

- Observed failure: shallow local A1R probes recover real but submaterial target
  direction under an interface that A1C later proved adequate.
- Target mechanism: the image-conditioned mapping needs nonlinear multiscale
  aggregation and global state, not a new action interface or local receptive
  field extension.
- Null hypothesis: the A1R signal is too weak or population-prior-like for the frozen
  global head to clear material gain and oracle-retention floors.
- Preferred causal hypothesis: assigning the fixed true target rather than the
  paired shuffled mapping will expose material image-conditioned direction
  accessibility under the frozen global head.
- Competing hypothesis or confound: a larger head can learn a generic direction without
  image-conditioned target access; the identical shuffled-target cell tests it.
- Cheapest observation that separates them: complete A1X outer-OOF safe replay
  for the true and shuffled mappings under the same folds, budget, and head.

Mechanism sentence:

```text
For untouched A1X clean-reference images, a fixed global nonlinear head using
only inference-eligible state should produce outer-OOF exact-half directions
that beat privileged shrink and a paired shuffled-target control if the A1R
bottleneck is deployable representation-to-action accessibility; failure to
clear the fixed material and retention floors closes only this head contract.
```

## Decision

- R3 design decision:
  `V4A_A1X_EXACT_HALF_DEPLOYABLE_INPUT_ACCESSIBILITY_DIAGNOSTIC_JUSTIFIED`.
- Scientific reason: A1R establishes nonzero image-conditioned signal but low
  material recovery, while A1C shows the exact-half interface retains ample
  privileged value. A global/nonlinear deployable-input mapping is therefore a
  distinct, falsifiable remaining accessibility question.
- Preservation reason: action space, exact-half transport, safety anchor,
  predecessor, bounds, support, operators, grids, and thresholds are unchanged.
- Independence reason: A1X remains untouched and is scored only through the
  frozen nested outer-fold contract.
- Cost/deployability reason: input eligibility and a fixed overhead budget are
  hard gates, but privileged amplitude selection prevents any candidate claim.
- Formal `PASS` authorizes only:
  `R3_REVIEW_FOR_SEPARATE_DIRECT_ACTION_CONTRACT_DESIGN_ONLY`.
- Formal `INCONCLUSIVE` authorizes only:
  `R3_REVIEW_OR_SAME_CONTRACT_EVIDENCE_REPAIR_ONLY`; no threshold, architecture,
  data, or budget change.
- Formal `FAIL` stops:
  `A1X_ACCESS_HEAD_DIRECT_TRAINING_POLICY_CANDIDATE_CONFIRMATION_CANARY_AND_LOCKED_TEST`.
